# PHP 8.1 Upgrade Design

## Goal

Release version `v2.0.0` of `wiejakp/captcha` as a PHP 8.1-native library while preserving the
documented captcha service API and factory behavior, correcting unsafe or inaccurate internals, and
retaining 100% class, method, and line test coverage.

## Support Policy

- PHP `^8.1` is the minimum and supported runtime constraint.
- `symfony/http-foundation` and `symfony/security-core` require `^6.4`.
- Development tests require `phpunit/phpunit` `^10.5`.
- PHPUnit 10 coverage requires PCOV or Xdebug; local verification uses PCOV 1.0.12.
- Composer dependency resolution for development targets PHP `8.1.0`, even when Composer is run
  from a newer local PHP installation.
- Dropping PHP 7 support is an intentional breaking compatibility change and requires version
  `v2.0.0`.
- `Equation` formally supports the same `+` and `-` operations generated by `ChallengeFactory`;
  accepting other executable PHP operators was incidental behavior and is removed.

## Branch and Repository Safety

- Create the exact branch requested by the user: `php81`.
- Preserve unrelated worktree changes if any appear before branch creation.
- Do not stage, commit, push, tag, or create a pull request.
- Do not commit `composer.lock` or `vendor/`; this repository remains a Composer library.
- Remove the tracked PHPUnit result cache and ignore PHPUnit-generated cache files.

## Dependency and Tooling Upgrade

Update `composer.json` to:

- require PHP `^8.1`;
- require Symfony HttpFoundation and Security Core `^6.4`;
- require PHPUnit `^10.5` for development;
- configure the development platform as PHP `8.1.0`;
- keep package metadata, PSR-4 namespaces, and existing runtime dependencies otherwise stable; and
- run PHPUnit without persisting result-cache changes in the repository; and
- suggest PCOV for line, method, and class coverage when Xdebug is unavailable.

Update `phpunit.xml.dist` to the PHPUnit 10.5 schema and retain strict handling of tests that perform
no assertions, risky tests, and warnings. Enable strict coverage metadata and keep `src/` as the
coverage source.

Dependency installation and validation will run through:

```bash
/opt/homebrew/opt/php@8.1/bin/php /usr/local/bin/composer
```

## Source Modernization

Modernize every class under `src/` consistently:

- add PHP 8.1 property types;
- make nullable parameters explicit;
- add explicit return types where existing behavior has a stable type;
- initialize nullable typed properties safely;
- retain existing namespaces, class names, public method names, defaults, and fluent return values;
- preserve localized number labels and non-negative positive-subtraction behavior; and
- preserve the existing challenge string and session-key formats.

Two internal correctness changes are included:

1. `CaptchaService` will store and return `SessionInterface`, not assume every supplied session is
   the concrete `Session` class. Supplying any valid `SessionInterface` implementation must work.
2. `Equation` will replace dynamic `eval()` execution with explicit `+` and `-` operator handling.
   Unsupported operators must continue to produce `InvalidEquationException` without executing
   arbitrary PHP.

These changes do not add new public classes or methods.

## Test Design

Retain all existing behavioral tests and modernize them for PHPUnit 10:

- replace PHPUnit docblock metadata with PHP attributes;
- add explicit `CoversClass` and `UsesClass` metadata;
- keep tests deterministic where fixed equation inputs are available;
- continue testing generated values within constrained single-value ranges; and
- keep separate-process session coverage for the default concrete session.

Use test-driven development for the two correctness changes:

1. Add a failing test proving `CaptchaService` accepts a non-concrete `SessionInterface`.
2. Add a failing test proving a syntactically valid but unsupported equation operator is rejected.
3. Make the minimal source changes required for each test to pass.
4. Modernize remaining type declarations only after the complete suite is green, preserving tested
   behavior throughout.

The finished suite must report:

- 100% classes;
- 100% methods; and
- 100% lines.

## Validation

Run all validation with the user's PHP 8.1 binaries:

```bash
/opt/homebrew/opt/php@8.1/bin/php /usr/local/bin/composer validate --strict
/opt/homebrew/opt/php@8.1/bin/php /usr/local/bin/composer update
/opt/homebrew/opt/php@8.1/bin/php /usr/local/bin/composer audit
/opt/homebrew/opt/php@8.1/bin/php vendor/bin/phpunit --configuration phpunit.xml.dist --do-not-cache-result
/opt/homebrew/opt/php@8.1/bin/php vendor/bin/phpunit \
    --configuration phpunit.xml.dist \
    --do-not-cache-result \
    --coverage-text
```

The coverage command requires PCOV or Xdebug to be loaded. Also run PHP 8.1 syntax checks over every
PHP file under `src/` and `test/phpunit/`, inspect the final diff, and confirm the worktree contains
only the intended uncommitted branch changes.
