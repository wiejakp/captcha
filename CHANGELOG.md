# wiejakp/captcha Changelog

All notable changes to this project will be documented in this file.


## [v2.0.0] - 2026-07-30

### Changed

* Raised the minimum PHP version to 8.1.
* Upgraded Symfony components to 6.4 and PHPUnit to 10.5.
* Modernized source and test declarations for PHP 8.1.
* Restricted equations to supported addition and subtraction without using `eval()`.
* Added strict coverage metadata while retaining 100% class, method, and line coverage.
